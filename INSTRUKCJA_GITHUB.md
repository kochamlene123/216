# 🚀 Jak opublikować stronę na GitHub (NAJPROSTSZA METODA)

## Krok 1: Utwórz konto na GitHub (jeśli nie masz)
1. Wejdź na: https://github.com
2. Zarejestruj się (Sign up)

## Krok 2: Utwórz nowe repozytorium
1. Po zalogowaniu kliknij **"+"** w prawym górnym rogu
2. Wybierz **"New repository"**
3. Wypełnij:
   - **Repository name**: `Ace2115.github.io` (WAŻNE: użyj swojej nazwy użytkownika!)
   - **Description**: (opcjonalnie) "mObywatel web app"
   - **Public** ✅ (zaznacz)
   - **NIE zaznaczaj** "Add a README file"
   - **NIE zaznaczaj** "Add .gitignore"
   - **NIE zaznaczaj** "Choose a license"
4. Kliknij **"Create repository"**

## Krok 3: Wgraj pliki przez przeglądarkę
1. Na stronie nowego repozytorium zobaczysz opcje
2. Kliknij **"uploading an existing file"** (lub po prostu przeciągnij pliki)
3. **Przeciągnij WSZYSTKIE pliki i foldery** z tego folderu:
   - `index.html`
   - `card.html`
   - `dane.html`
   - `documents.html`
   - `home.html`
   - `id.html`
   - `more.html`
   - `pozostałe.html`
   - `qr.html`
   - `qr2.html`
   - `services.html`
   - `zastzrzez.html`
   - `README.md`
   - **Cały folder `assets`** (przeciągnij cały folder)
   - **Cały folder `images`** (przeciągnij cały folder)
4. Na dole strony wpisz wiadomość: `Initial commit`
5. Kliknij **"Commit changes"**

## Krok 4: Włącz GitHub Pages
1. W repozytorium kliknij **"Settings"** (na górze)
2. W menu po lewej znajdź **"Pages"**
3. W sekcji **"Source"**:
   - Wybierz **"Deploy from a branch"**
   - Branch: wybierz **"main"**
   - Folder: wybierz **"/ (root)"**
4. Kliknij **"Save"**
5. Poczekaj 1-2 minuty

## Krok 5: Sprawdź czy działa
1. GitHub pokaże Ci link: `https://Ace2115.github.io` (lub Twoja nazwa)
2. Otwórz ten link w przeglądarce
3. Jeśli widzisz stronę - działa! ✅

## 📱 Jak dodać na telefonie:
1. Otwórz link `https://Ace2115.github.io` w przeglądarce na telefonie
2. **iOS (Safari)**: 
   - Kliknij przycisk "Udostępnij" (strzałka w górę)
   - Wybierz "Do Ekranu głównego"
3. **Android (Chrome)**:
   - Kliknij menu (3 kropki w prawym górnym rogu)
   - Wybierz "Dodaj do ekranu głównego"

## ⚠️ WAŻNE:
- Nazwa repozytorium MUSI być: `TwojaNazwaUżytkownika.github.io`
- Jeśli Twoja nazwa użytkownika to np. "JanKowalski", to repozytorium nazwij: `JanKowalski.github.io`
- GitHub automatycznie opublikuje stronę pod tym adresem

## 🔄 Aktualizacja strony w przyszłości:
- Wgraj zmienione pliki tak samo jak w Kroku 3
- GitHub automatycznie zaktualizuje stronę (może potrwać 1-2 minuty)
